# Adarsha Vimukthikani

A fully redesigned, multi-page portfolio implemented in the existing project. React, Vite, JSX, React Router, Tailwind CSS, and Motion for React. Frontend only.

## Run locally

```powershell
cd "C:\Users\ASUS\Desktop\Adarsha Vimukthikani\portfolio"
npm.cmd run dev
```

Open the Local URL printed by Vite. Dependencies are already present in this workspace. For a fresh checkout, use `npm.cmd ci` first. On macOS/Linux, use `npm` in place of `npm.cmd`.

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run test:browser
npm.cmd run preview
```

## Structure

```text
src/
  app/                    Application, router, theme provider
  layouts/                Persistent page shell and metadata
  pages/                  Eight individual pages and a 404
  components/common/      Shared content, logos, preview dialog
  components/navigation/  Header and footer
  components/visuals/     Original HTML/CSS/SVG compositions
  data/                   Profile, navigation, articles, learning, brands
  styles/                 Palette, layouts, responsive rules, motion
public/                   Only production assets and hosting support
docs/                     Source evidence, asset provenance, audit
backups/                  Recovery checkpoints, excluded from the build
```

The palette is neon lime `#D0F344`, cold brew `#2C211D`, sky `#C2D8E5`, and cream `#F6F3EC`. Dark mode uses espresso surfaces. Official logo and credential artwork keeps its original colours. The original photograph appears only on Home. About uses a new illustration generated from the real photo.

## Hosting

Publish `dist/`, generated by `npm.cmd run build`. Both hosting configurations assume this `portfolio` folder is selected as the project root:

- Netlify: `netlify.toml` sets the build and publish directories; `public/_redirects` includes the HTTP 200 SPA fallback.
- Vercel: `vercel.json` rewrites route requests to `index.html`.
- Apache: `public/.htaccess` supplies a rewrite when mod_rewrite is enabled.

If Netlify is configured from the parent workspace, set its base directory to `portfolio`. If Vercel imports the parent workspace, select `portfolio` as its Root Directory. Serve over HTTP rather than opening `dist/index.html` as a file.

The browser suite tests the production files through their SPA fallback, including direct route requests and refreshes. This is local hosting verification; no external deployment was performed.

Retired campus imagery, painted portraits, duplicate fonts, and obsolete asset-preparation scripts are outside the active build in `docs/archive/`.

The latest route screenshots and machine-readable acceptance report are in `test-results/v4/`. Open [the visual review gallery](docs/preview-gallery.html) to compare pages and themes. Run the test command to regenerate these local QA artifacts.
